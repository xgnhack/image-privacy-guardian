# 图像隐私守护者 - 资源优化策略文档

## 1. 问题分析

### 1.1 当前资源消耗问题
- **首次扫描瓶颈**：大量文件同时处理导致内存和CPU占用过高
- **线程管理不当**：固定3个并发线程限制，无法根据系统资源动态调整
- **内存泄漏风险**：长时间运行时图像处理可能导致内存累积
- **UI响应性差**：主线程被阻塞，界面卡死
- **缺乏进度反馈**：用户无法了解处理进度，体验差

### 1.2 资源消耗热点
- 图像文件的加载和处理（PIL/OpenCV操作）
- 大量文件的哈希计算
- 并发线程的创建和管理
- 文件系统的频繁I/O操作

## 2. 核心优化策略

### 2.1 智能分批处理机制

#### 2.1.1 分批扫描策略
```python
class BatchProcessor:
    def __init__(self):
        self.batch_size = 50  # 每批处理文件数
        self.batch_delay = 100  # 批次间延迟(ms)
        self.max_memory_usage = 512 * 1024 * 1024  # 512MB内存限制
        
    def process_files_in_batches(self, file_list):
        """分批处理文件列表"""
        for i in range(0, len(file_list), self.batch_size):
            batch = file_list[i:i + self.batch_size]
            self.process_batch(batch)
            
            # 内存检查和清理
            if self.get_memory_usage() > self.max_memory_usage:
                self.force_garbage_collection()
                
            # 批次间休息
            time.sleep(self.batch_delay / 1000)
```

#### 2.1.2 动态批次大小调整
- 根据系统内存使用情况动态调整批次大小
- 监控处理速度，自适应优化批次参数
- 在高负载时减少批次大小，低负载时增加

#### 2.2.1 优先级队列
```python
class PriorityQueue:
    def __init__(self):
        self.high_priority = []  # 用户手动添加的文件
        self.normal_priority = []  # 监控发现的新文件
        self.low_priority = []  # 首次扫描的文件
        
    def add_task(self, file_path, priority='normal'):
        """添加处理任务"""
        task = {
            'file_path': file_path,
            'timestamp': time.time(),
            'priority': priority
        }
        
        if priority == 'high':
            self.high_priority.append(task)
        elif priority == 'low':
            self.low_priority.append(task)
        else:
            self.normal_priority.append(task)
```

#### 2.3.1 自适应线程数量
```python
class AdaptiveThreadPool:
    def __init__(self):
        self.min_threads = 1
        self.max_threads = min(8, os.cpu_count())
        self.current_threads = 2
        self.load_threshold = 0.8
        
    def adjust_thread_count(self):
        """根据系统负载调整线程数"""
        cpu_usage = psutil.cpu_percent(interval=1)
        memory_usage = psutil.virtual_memory().percent
        
        if cpu_usage > 80 or memory_usage > 85:
            # 高负载时减少线程
            self.current_threads = max(self.min_threads, self.current_threads - 1)
        elif cpu_usage < 50 and memory_usage < 60:
            # 低负载时增加线程
            self.current_threads = min(self.max_threads, self.current_threads + 1)
```

class MemoryManager:

### 2.5 进度反馈和用户体验

#### 2.5.1 详细进度显示
```python
class ProgressTracker:
    def __init__(self):
        self.total_files = 0
        self.processed_files = 0
        self.current_file = ""
        self.start_time = None
        
    def update_progress(self, current_file):
        """更新处理进度"""
        self.processed_files += 1
        self.current_file = current_file
        
        progress_percent = (self.processed_files / self.total_files) * 100
        elapsed_time = time.time() - self.start_time
        estimated_total = elapsed_time * self.total_files / self.processed_files
        remaining_time = estimated_total - elapsed_time
        
        return {
            'percent': progress_percent,
            'current_file': os.path.basename(current_file),
            'processed': self.processed_files,
            'total': self.total_files,
            'remaining_time': remaining_time
        }
```
